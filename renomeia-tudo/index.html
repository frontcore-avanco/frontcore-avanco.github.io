Renomeia Tudo

Troca, remove ou renomeia partes do nome de vários arquivos de uma vez Ajuda / Como utilizar
Disponível

Escolha uma pasta, diga o que deve mudar no nome dos arquivos e confira a prévia antes de executar. Só o nome é alterado — o conteúdo dos arquivos nunca é tocado.

Ajuda / Como utilizar

O que a ferramenta faz

Aplica uma regra ao nome de todos os arquivos de uma pasta. Ela só muda o nome: o arquivo em si fica intacto, e as subpastas (e o que há dentro delas) não são mexidas. Funciona no Chrome e no Edge — são os navegadores que deixam um site alterar arquivos numa pasta que você autoriza.

Substituir texto

Troca um trecho do nome por outro.

  • OK_Contingencia → Contingencia: procurar OK_ e deixar "Trocar por" vazio.
  • nota_2024.pdf → NF_2024.pdf: procurar nota, trocar por NF.

"Aplicar em" escolhe onde procurar: no nome (sem a extensão), só na extensão ou no nome completo. Por padrão não diferencia maiúsculas de minúsculas e troca todas as ocorrências.

Remover caracteres

Apaga uma quantidade de caracteres a partir de uma posição. A posição 1 é o primeiro caractere (ou o último, se você contar a partir do fim).

  • Remover os 3 primeiros: OK_Contingencia → Contingencia (a partir do início, posição 1, quantidade 3).
  • Remover os 2 últimos: relatorio_01 → relatorio_ (a partir do fim, posição 1, quantidade 2).

Renomear caracteres

Troca uma quantidade de caracteres, a partir de uma posição, por um texto novo.

  • Contingencia_0102: trocar os 2 primeiros caracteres (Co) por XX → XXntingencia_0102 (posição 1, quantidade 2).
  • Com quantidade 0 nada é apagado, o texto só é inserido: Contingencia → OK_Contingencia (posição 1, quantidade 0, texto OK_).

Trocar a extensão

Use Substituir texto com "Aplicar em: Extensão": procurar txt, trocar por pdf → a.txt vira a.pdf. Isso só muda o nome da extensão — não converte o conteúdo do arquivo para outro formato.

Prévia, conflitos e desfazer

  • A prévia mostra o nome atual e o novo de cada arquivo, antes de qualquer alteração.
  • Conflito: o novo nome já existe na pasta, ou mais de um arquivo ficaria com o mesmo nome. Esses arquivos não são renomeados.
  • Não permitido: o nome ficaria vazio, teria caracteres que o Windows não aceita (\ / : * ? " < > |) ou a posição escolhida está além do tamanho do nome.
  • Depois de executar, o botão Desfazer devolve os arquivos aos nomes de antes.
  • Arquivo aberto em outro programa pode não ser renomeado — o resultado mostra quais falharam e por quê.
